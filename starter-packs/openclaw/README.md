# SourceHarbor OpenClaw Pack

This is the first public OpenClaw-shaped starter pack for SourceHarbor.

Use it when you want:

- the quickest OpenClaw compatibility path
- a public starter that points at MCP, HTTP API, CLI, and SDK
- a public OpenClaw-shaped skill example without relying on repo-private `.agents/skills`

Start here:

- `docs/compat/openclaw.md`
- `starter-packs/openclaw/sourceharbor-mcp-template.json`
- `templates/public-skills/openclaw/sourceharbor-watchlist-briefing.md`
- `examples/openclaw/README.md`
- `examples/openclaw/skills/sourceharbor-watchlist-briefing/SKILL.md`

Honest boundary:

- this is a first-cut compatibility pack
- it is not a registry-published OpenClaw plugin
- it is not a plugin marketplace claim
